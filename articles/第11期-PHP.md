每天认识一门编程语言第十一期——PHP

写在前面

1994 年，一个程序员有个小烦恼：他想知道几个人看过自己挂在网上的简历。为了数清这个数，他写了个小工具。三十多年后，它还在给互联网上大多数网站打工。

这位程序员叫 Rasmus Lerdorf。当年网页上的小杂活多半归 Perl 打理，他的简历页就跑着一摞 Perl 脚本，每次有人点开，服务器都得把整套 Perl 环境拉起来跑一遍，又慢又吵。他嫌烦，干脆用 C 把这堆脚本改写成几个紧凑的小程序，统一取名 Personal Home Page Tools。

[推荐配图：1995 年风格的个人主页，灰底蓝字，角落一枚简陋的访客计数器，数字定格在 000123]

后来他把源码公开，别人不断往里添功能，这门"简历计数器"就这么一路长成了大半个互联网的地基。

开发者简介

1995 年 6 月 8 日，Rasmus 在新闻组发帖，宣布 Personal Home Page Tools 1.0 开放源码，原话大意是"一套用 C 写的小巧紧凑的 CGI 程序"。CGI，就是让网页服务器调用外部程序来生成页面的老规矩。这份公告，如今被当作 PHP 的官方生日。

Rasmus 的脾气从他的话里能听出来。他在 SitePoint 的采访里说："PHP 就跟你的牙刷差不多。你每天用它，它把活干了，就这样。谁会想读一篇讲牙刷的文章呢？"2016 年接受 Siliconrepublic 采访时，他说得更直白："我其实讨厌编程，但我喜欢解决问题。"

真正的转机在 1997 年。以色列的两个学生 Zeev Suraski 和 Andi Gutmans 嫌它慢，动手重写了核心，1998 年发布 PHP 3，名字也从 Personal Home Page 改成 PHP: Hypertext Preprocessor，这个缩写展开之后还包含 PHP 自己。两人随后创办 Zend 公司，把重写成果做成了后来二十年的发动机。从这年起，它才算一门正经语言。

主要内容

PHP 干活的方式，今天看依然朴素：写个网页文件，HTML 照常写，需要动态的地方插一段 `<?php` 开头的代码，服务器执行完，把结果连同 HTML 一起发回浏览器。这门语言的性格就是怎么省事怎么来。

二十多年前的教材第一课是给网站数访客，今天的教材第一课，基本还是它：

```php
<?php
$hits = (int) file_get_contents("counter.txt") + 1;
file_put_contents("counter.txt", $hits);
echo "你是第 $hits 位访客";
```

五行，一个能记住访问次数的网页就成了。$hits 这种 $ 开头的变量名，还是当年从 Perl 学来的家规。

省事的另一面是坑。字符串当数字使，数字当字符串使，PHP 会悄悄替你换算，行话叫"弱类型"。PHP 8 以前，数字 0 和字符串 "foo" 比较，结果居然是相等，因为任何字符串转成数字都得落回 0。这么明显的荒唐，它将就了二十五年，直到 2020 年 11 月的 PHP 8.0 才改掉，那次改动的说明标题，直译过来叫《更通情达理的字符串与数字比较》。

体量能说明这种"将就"的含金量。Web 技术调查机构 W3Techs 2026 年 10 月的数据：能查明服务端语言的网站里，69.3% 靠 PHP 生成页面；光 WordPress 这一个建站程序，就驱动着全球约四成的网站；早年 Facebook 整站也是 PHP 写的。2015 年 12 月发布的 PHP 7，官方口径速度翻了一倍。中间还有个插曲：原定大幅翻新的 PHP 6 烂了尾，具体哪年放弃，资料说法不一，大约在 2010 年；加上市面上印过《PHP 6》教程，社区干脆投票跳过 6，直接发 7。

一些论点

被骂也是实打实的。2012 年 4 月，博主 Eevee 发了篇长文，标题就叫《PHP: a fractal of bad design》，大意是：PHP 是一个由糟糕设计构成的分形——放大任何一处，都能看到一模一样的混乱——文中细数了几百条自相矛盾。流传最广的例子是参数顺序：查"字符串里有没有某个词"，用 strpos($haystack, $needle)，干草堆在前；查"数组里有没有某个值"，用 in_array($needle, $haystack)，针在前。同一对词，方向相反，写一次查一次文档。

[推荐配图：自相似的分形螺旋，每一圈里都长着更小的同款螺旋，深色底，极简线条风]

中文论坛的版本更短。吵架帖里总有人甩出那句"PHP 是世界上最好的语言"，一半反讽，一半挑衅，从贴吧刷到 V2EX，刷了十几年。骂声没停过，用的人也没少过：W3Techs 的曲线里，它的份额从 2021 年的八成多缓步降到今天的近七成，依然是第一。

檄文之后，PHP 真改了不少：给变量规定类型的功能进了语法，0 和 "foo" 不再相等，2025 年 11 月 20 日发布的 PHP 8.5 还添了个顺手的小语法，上一步的输出可以直接喂给下一步当输入。可 strpos 的参数顺序，到今天还是老样子。"先跑起来，优雅慢慢补"的路线能一个坑一个坑地填，填不动的是既成事实：一个装着全球几成网站的家，没法推倒重排。

要是明天让我写个小站，我会直接新建一个 .php 文件开写，而不是先读半小时设计理念；但 strpos 的那两个参数，我每次都得查。两句话都是真心话。

说回开头那份简历。它早就没人看了，访客计数器却老老实实数到今天，如今住在每本 PHP 教材的第一章。它的作者 2016 年接受采访时说的还是那句话：他讨厌编程，只是喜欢解决问题。
