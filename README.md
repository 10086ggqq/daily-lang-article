# daily-lang-article

一个用于撰写《每天认识一门编程语言》系列科普文的 **Agent Skill**。从定版本、选定语言、收集素材（社区梗、可查证名言与真实吐槽），到成稿、事实核查、登记索引，稳定产出一篇 **2000 字以内、四节结构、收尾克制** 的幽默科普文。同一套骨架分两版：**哲学版**以语言的哲学面为取景框；**热点版**以近期热点事件为钩子（用户上传优先，否则自行搜索），再讲这门语言和「谁用它做成了什么」的小故事。

成品气质：像给懂行的朋友写连载——短句、口语、有真材料；哲学或热点只是取景框，不是布道；观点有站位。反 AI 味三条红线：**结尾不升华、结构不对称、细节要具体**。

## 工作流

1. **定版本**：用户点名按点名的来；没点名但上传了热点素材 → 热点版；都没有 → 哲学版。
2. **定语言与期数**：查 `期数索引.md` 避开已写语言；期数 = 表中最大期数 + 1，用户指定时以用户为准。热点版的热点用户上传优先，否则自行搜索最近约四周的科技圈热点。
3. **收集素材**：哲学版复制 `references/素材收集模板.md`，热点版复制 `references/素材收集模板-热点版.md` 填素材卡，查不到的标「暂缺」。
4. **写初稿**：按 `SKILL.md`「写作规范」（通用 + 本版专属）直接成文。
5. **事实核查**：对照 `references/事实核查清单.md` 逐条核验。
6. **自检**：对照 `SKILL.md`「成稿自检」逐条给出「通过/不通过 + 依据」。
7. **落盘登记**：保存 `articles/第X期-语言名.md` 与素材卡，在 `期数索引.md` 追加一行并重读核对。

## 硬性约束（节选）

- 标题《每天认识一门编程语言第 X 期——语言》；恰好四个小标题：写在前面 / 开发者简介 / 主要内容 / 一些论点
- 开头 50–80 字钩子，开场方式与本版最近两期不重样；全文 ≤2000 字（不含代码块与配图标记）
- ≥1 段经典代码（围栏 + 语言标注）；≥2 处 `[推荐配图：……]`；1–2 个术语当场讲白
- 一门冷门语言客串、在前半部分出现（排除已写语言与知名语言）
- 结尾不升华：无格言警句收束，最后一段落在具体事物上；热点版另禁「这件事告诉我们」式句式
- 热点版：开头以热点事件为钩子（用户上传优先，否则自搜，连接点必须真实直接），正文 ≥1 个「谁用它做成了什么」的带出处小故事
- 人味三件套：≥3 处硬细节、≥1 条带出处的社区声音、≥1 处明确表态
- 不分点、不自我介绍、无写作流程痕迹
- 直接引语必有出处，统计数字必有来源

## 目录结构

```

├── SKILL.md                            # 工作流 + 写作规范（两版）+ 自检清单
├── 期数索引.md                          # 已写语言台账，含版本列（写前查、写后登记）
├── README.md
├── LICENSE.txt                          # MIT
├── articles/
│   ├── 第8期-Rust.md                   # 哲学版示范成稿
│   └── 第11期-PHP.md                   # 哲学版成稿
└── references/
    ├── 素材收集模板.md                  # 哲学版第 3 步素材卡
    ├── 素材收集模板-热点版.md           # 热点版第 3 步素材卡（含热点事件卡）
    ├── 事实核查清单.md                  # 第 5 步核查条目（含热点事件一节）
    ├── 素材-第X期-语言名.md             # 每期素材卡存档（命名示例）
    ├── 范文-Clojure第七期.md            # 早期风格存档（「尾声」已废弃）
    └── 提示词示例-Clojure第七期.md      # 外部提示词打包格式参考（旧版存档）
```

## 安装

把整个目录放入你的 Agent Skills 目录（与其他 Skill 同级），重启或刷新后，通过 `SKILL.md` frontmatter 中的 `description` 触发；也可以直接说「用 daily-lang-article 写一期 Haskell」（哲学版）或「结合最近的 XX 事件写一期 Go」（热点版，也可直接丢给它一条新闻链接）。首次在空目录使用时，Skill 会先建好索引表和目录骨架。
