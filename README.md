# daily-lang-article · 每天认识一门编程语言

一个用于撰写《每天认识一门编程语言》系列科普文的 **Agent Skill**。从选定语言、搜集「哲学梗 / 社区绰号 / 名言」，到组装提示词，稳定产出一篇 **2000 字以内、哲学轻文学风格、固定四段式结构** 的幽默科普文。

成品气质：理性但不端着，像哲学系实习生在和你聊天；只用一两个学术名词并当场讲明白；有经典代码、有配图建议、有批判性思考，唯独没有 AI 腔。

## 工作流程

1. **确定语言**：先查 `期数索引.md` 避开已写过的语言，再由用户指定或参考 TIOBE / PYPL 等榜单挑选。
2. **搜集素材**：复制 `references/素材收集模板.md`，收集笑话与绰号、哲学主张、名言名句、代码与配图灵感、对立观点。
3. **组装提示词**：参考 `references/提示词示例-Clojure第七期.md`，把素材填入 `SKILL.md` 的模板。
4. **产出并登记**：生成正文，对照硬性约束清单自检修订，定稿后在 `期数索引.md` 登记。

## 硬性约束（节选）

- 标题：《每天认识一门编程语言第 X 期——语言》
- 恰好四个小标题：写在前面 / 开发者简介 / 主要内容 / 一些论点
- 开头约 60 字钩子；全文 ≤2000 字
- 代码用围栏包裹；≥2 处 `[推荐配图：……]` 标记
- 用一门冷门语言（Clojure / Elixir / Erlang / Haskell / Squirrel / Pawn / AngelScript 等）在文章前部客串、承上启下
- 不分点、不自我介绍、不暴露写作者身份与模仿风格

## 安装

把整个目录放入你的 Agent Skills 目录（与其他 Skill 同级），重启或刷新后，通过 `SKILL.md` frontmatter 中的 `description` 触发；也可以直接说「用 daily-lang-article 写一期 Rust」。
